# Number.Power

The examples show null propagation, negative exponents, and a negative base raised to a fractional power.

```m
Number.Power(2, null)
```

```text
null
```

```m
Number.Power(2, -3)
```

```text
0.125
```

```m
Number.Power(-8, 1 / 3)
```

```text
#nan
```
