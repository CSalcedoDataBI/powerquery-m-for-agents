# Number.Log

These examples show the default base, an explicit base, and how a null input is handled.

```m
Number.Log(2)
```

```text
0.69314718055994529
```

```m
Number.Log(2, 10)
```

```text
0.3010299956639812
```

```m
Number.Log(null, 10)
```

```text
null
```
